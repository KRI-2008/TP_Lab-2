# TP_Lab-2 — Учебная лабораторная работа по веб-безопасности

> ВНИМАНИЕ: Данный репозиторий создан исключительно в учебных целях для изучения механизмов веб-уязвимостей и методов их устранения. Запускать и эксплуатировать только на виртуальной машине в изолированной среде. Использование кода против реальных систем без разрешения владельца запрещено.

---

## Описание проекта

Учебное веб-приложение на Python (Flask) с двумя намеренно внедрёнными уязвимостями из списка OWASP Top 10 (2021). Проект демонстрирует полный цикл: от разработки уязвимого кода через его эксплуатацию до написания патча, закрывающего уязвимости.

Цель работы — понять, как возникают уязвимости на уровне кода, почему они опасны и как их правильно исправлять.

## Технологический стек

- Язык: Python 3.6+
- Фреймворк: Flask 2.0.3

## Функционал приложения

Приложение предоставляет HTTP-эндпоинты для приветствия, сетевой диагностики (пинг хоста) и прокси-запроса (получение содержимого указанного URL). Параметры передаются через GET-запросы.

## Реализованные уязвимости

### 1. Command Injection — OWASP A03:2021 (Injection)

**Где:** функция `ping()` в `Z_app.py`

**Суть:** пользовательский ввод напрямую конкатенируется в строку shell-команды с флагом `shell=True`. Это позволяет атакующему разорвать команду символом `;` и выполнить произвольную команду на сервере.

**Пример эксплуатации:**
```
GET /ping?host=127.0.0.1;id
```
В ответе сервер вернёт вывод команды `id`, выполнившейся с правами процесса Flask.

**Уровень опасности:** Critical (CVSS ~9.8) — Remote Code Execution.

---

### 2. SSRF — OWASP A10:2021 (Server-Side Request Forgery)

**Где:** функция `fetch()` в `Z_app.py`

**Суть:** сервер выполняет HTTP-запрос по любому URL, переданному клиентом, без валидации. Это позволяет атакующему использовать сервер как прокси для доступа к внутренним ресурсам: localhost, локальной сети, метаданным облачных провайдеров.

**Пример эксплуатации:**
```
GET /fetch?url=http://192.168.0.1
```
Сервер обратится к роутеру локальной сети и вернёт HTML его админ-панели.

**Уровень опасности:** High (CVSS ~7.5) — обход периметра сети.

## Патч безопасности

Файл `Z_app_patch.diff` содержит unified diff, который устраняет обе уязвимости:

- **Command Injection:** whitelist-валидация хоста через `re.fullmatch()` + передача команды списком аргументов без `shell=True`
- **SSRF:** функция `is_safe_url()`, блокирующая приватные, loopback и link-local IP-диапазоны (RFC 1918)

Применение патча:
```bash
patch Z_app.py < Z_app_patch.diff
```
